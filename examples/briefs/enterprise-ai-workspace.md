# Enterprise AI workspace example

Use `$motionsites-design` to redesign an existing enterprise AI question-answering workspace.

Preserve:

- primary navigation and every destination;
- collapsible conversation history, new conversation, historical restore, and delete;
- AI and user messages, citations, quick actions, attachments, tool entry, and send behavior;
- service/data status, permissions, authentication, and API contracts.

Goals:

- Desktop baseline: 1440px.
- Compact navigation and conversation history.
- Conversation is the visual center, with a comfortable reading measure.
- System state is visible but subdued.
- Avoid large empty areas and unnecessary cards.
- Verify keyboard operation, scroll behavior, 1024px and 390px layouts, and reduced motion.
