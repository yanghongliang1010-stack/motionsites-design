# Contributing

Contributions are welcome for original design directions, safer catalog tooling, documentation, tests, and verification workflows.

1. Create a focused branch.
2. Keep new starter patterns original and add source/licensing notes when relevant.
3. Run `python3 -m unittest discover -s tests -v`.
4. Run the Skill and plugin validators described in `docs/INSTALL.md` when available.
5. Open a pull request explaining the user problem, design decision, and verification evidence.

Do not submit copied prompt bodies, preview media, paywalled material, credentials, or cloned third-party pages.
