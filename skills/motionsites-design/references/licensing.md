# Catalog and licensing boundaries

The bundled starter patterns are original project content released under this repository's MIT license.

The optional remote catalog points to public third-party metadata. Entries may reference prompts, images, videos, or designs with separate creator rights.

1. Use metadata to discover a direction.
2. Fetch a single prompt only when necessary and explicitly intended.
3. Treat the result as research material and translate principles into a new implementation.
4. Do not redistribute third-party prompt bodies or media in this repository.
5. Do not bypass subscriptions, authentication, access controls, or attribution.
6. Check original source terms before commercial reuse of external assets.
